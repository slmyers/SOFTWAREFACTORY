# Todo App Spec

## Goal
Build a simple command-line todo application.

## Features
- Add a new todo item
- List all todo items
- Mark a todo item as complete
- Delete a todo item

## Acceptance Criteria
- `add <task>` creates a new todo entry
- `list` shows all pending and completed items
- `complete <id>` marks a task done
- `delete <id>` removes a task
